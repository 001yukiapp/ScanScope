ScanScope フロアシート — ID 44〜47

このシートの使い方
1. 下の4枚の枠に tag36h11 の ID 44〜47 の本物タグ画像を重ねて配置します
2. PCの画面またはA3印刷で床に置きます
3. タグ中心間距離が 200mm になるようDPIスライダーで調整してください

タグ画像の入手方法（いずれか）
・Pythonで生成: pip install apriltag && python generate_tags.py（同梱スクリプト）
・オンライン: 「AprilTag generator tag36h11」で検索 → ID 44〜47を保存
・公式リポジトリ: AprilRobotics/apriltag-imgs の tag36h11/ フォルダ
中心間隔: -

検出確認（カメラで映して確認）

align4.htmlで床タグが検出されたか確認できます。このページはレイアウトのみ提供します。

※ 床タグが検出されない場合は「固定カメラモード」でも4輪測定が可能です（カメラを動かさない方式）。
